# 无密数据工程化策略

真实项目的招标文件、点位表、渠道价格、网络拓扑和内部审批资料不进入公共知识库，也不需要上传给模型。项目按三层数据工作：

## 公开事实层

只放可以公开核验的内容：

- 大华官网产品详情、公开技术参数和公开方案；
- 官方公开案例和公开配单；
- 已公开的行业标准、接口说明和产品手册；
- 产品来源页、采集时间和原文片段。

这部分可以持续爬取、去重、重建索引，并作为方案证据。

## 工程规则层

不依赖任何客户机密，沉淀成程序规则：

- 点位、码流、录像天数、存储和带宽计算；
- NVR 通道、硬盘盘位、交换机端口和 PoE 功率校验；
- 设备、平台、授权和网络的兼容关系；
- 读标、方案设计、内部评审、投标响应和交付归档流程；
- 缺口、风险、证明材料和人工确认项。

这部分决定系统是否像一个真正的售前工具，不能依赖某个项目的原始文件。

## 本地项目层

真实项目数据只保存在用户电脑：

- 招标文件和附件；
- 现场勘察表、点位表、网络草图；
- 渠道价、折扣、成本和毛利；
- 内部评审意见、客户名称和联系人；
- 项目版本、审批记录和最终交付包。

本地项目层可以引用公开事实层，但不反向上传客户原文。对外演示和自动化测试只使用脱敏或合成项目。

## 当前开发原则

1. 公共数据只负责“证明产品和方案存在”。
2. 工程规则负责“检查方案是否成立”。
3. 项目文件负责“描述这个客户的实际情况”。
4. 任何无法从公开资料或本地项目证据确认的内容，都显示为“待确认”，不自动补成满足。

后续新增行业能力时，先增加工程规则和合成测试案例，再接入公开资料，最后才允许本地项目使用。
