      使用教程

      1. 选模板或自己写：点击上方的「快速体验模板」一键填入典型需求；也可在文本框自由描述（如"周界80路、电梯20路、存储30天"）。
      2. 启动 Agent：点「启动 Agent」。系统先解析需求、自动选型、确定性测算存储/带宽。
      3. 补信息 / 审阅：信息不足会回问，按提示补充即可；方案出来后在审阅页改数字或写意见，会重新计算。
      4. 看拓扑图：通过后默认看「建议拓扑」，点「工程拓扑」可切换到三列工程建议图（前端采集 / 传输与存储 / 平台与显示），看清每类设备用在哪、怎么连。
      5. 导出：可下载 Word 方案、建议拓扑图、工程拓扑图，或点「导出当前图 PNG」保存正在看的那张。
